# 🎧 StudioRemix

**Music Video Maker** buat anak DJ / Remix.
Upload lagu -> Ganti Cover -> Atur Equalizer -> Render jadi Video 9:16 siap upload ke TikTok.

### ✨ Fitur
- [x] Upload Lagu MP3
- [x] Ganti Cover Foto
- [x] Edit Judul & Artist
- [x] Equalizer 7 Band (Real Audio API)
- [x] Potong Lagu + Waveform
- [x] Visualizer iOS / Wave / Circle
- [x] Efek 8D, Filter, Reverb, Kecepatan
- [x] Render Video 720p / 1080p, 30 / 60 FPS
- [x] Orientasi Potret 9:16 & Lanskap 16:9

### 🚀 Cara Pakai
1. Buka https://rhmdprtma.github.io/StudioRemix/
2. Klik `+ Upload Song`
3. Pilih lagu & foto cover
4. Atur equalizer & potongan
5. Klik `Render Video` -> Download!
