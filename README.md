## 🎛️ Fitur

**🎵 AUDIO**
- Equalizer 8 Band (60Hz - 16KHz) - Beneran ngaruh ke suara
- LOW PASS / HIGH PASS - Kiri = Mendem, Kanan = Cempreng
- Potong Lagu + Waveform
- Kecepatan 0.75x - 1.5x, Efek 8D, Reverb

**📱 PLAYER IPHONE**
- Kaca Blur ngikutin Cover
- Visualizer 4 Batang gerak ngikutin beat
- Tombol ↺10 ❚❚ ↻10 + AirPlay

**🎬 VIDEO**
- Render 720p / 1080p, 30 / 60 FPS
- Potret 9:16 & Lanskap 16:9
- Visualizer iOS / Wave / Circle

## 🚀 Cara Pakai (30 Detik)

1. Buka https://rhmdprtma.github.io/StudioRemix/
2. Klik `+ Upload Song` -> Pilih lagu MP3
3. Tap Cover -> Pilih foto cover lu
4. Atur Equalizer & Filter LOW / HIGH PASS
5. Potong lagu 15 / 30 detik buat TikTok
6. Klik `Render Video` -> Download!
7. Upload ke TikTok, tag @mctama 😎

## 🛠️ Teknologi

Cuma pakai **HTML aja**, tapi di dalamnya ada 3 otak:
`HTML (Kerangka) + CSS (Tampilan) + JavaScript (Otak)`

- **Web Audio API** -> Equalizer & Filter beneran
- **Canvas API** -> Visualizer & Render Video
- **MediaRecorder API** -> Export jadi MP4
- **Zero Server** -> Semua di HP lu, privasi aman
